# CGPA Calculator

A simple web-based CGPA Calculator that helps students calculate their Cumulative Grade Point Average (CGPA) quickly and accurately. The application provides an intuitive interface for entering grades and computing the overall CGPA.

---

## Features

- Calculate CGPA instantly.
- Simple and easy-to-use interface.
- Lightweight and responsive design.
- Fast and accurate calculations.
- Runs entirely in the browser.
- No installation or backend required.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/JennaSanks/CGPA_calculator.git
cd CGPA_calculator
```

No additional dependencies are required.

---

## Running the Project

Open the `index.html` file in any modern web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

---

## Usage

1. Open the application.
2. Enter the required grades or grade points.
3. Calculate the CGPA.
4. View the computed result instantly.

---

## Project Workflow

1. User opens the web application.
2. Grade inputs are entered.
3. The application processes the values.
4. The CGPA is calculated.
5. The result is displayed on the page.
